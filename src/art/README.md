# Optional illustrations

Images placed here are picked up automatically at build time by `src/artwork.ts`; anything missing falls back to the built-in graphics. File names and sizes are specified in `docs/ART_BRIEF.md`.

- `foes/<bestiary id>.webp` — enemy portraits
- `relics/<relic id>.webp` — relic icons
- `sites/<kind>.webp` — map pictograms and keeper tokens
- `scenes/<lore id>.webp` — story, ending and defeat illustrations
